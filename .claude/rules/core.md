# Core Kernel Rules

`core/` is the innermost ring. It knows nothing about Fire TV, Shields, PCs, or Kodi.

1. **No device-specific or app-specific knowledge** — no package names, no vendor quirks, no `.kodi` paths. If a workaround exists for one vendor's bug, it belongs in that pack as data.
2. **No imports from `packs/` or `apps/`** — dependencies point inward only. A violation here is an architecture bug, not a style nit.
3. **Seams are `Protocol`s, not ABCs** — structural typing, no inheritance required to satisfy one.
4. **A seam ships with two adapters or it isn't a seam** — one adapter is hypothetical. The second is usually the test double (`FakeTransport`, `LocalArtifactStore`, `InMemoryAuditSink`).
5. **Segregate interfaces** — `Reachable` / `CommandRunner` / `FileTransfer` compose into `Transport`. A probe depends on `CommandRunner`, not on all of it.
6. **Construct nothing** — dependencies arrive via `StepContext` or a constructor. No module-level singletons, no `AdbTransport(...)` inside a step.
7. **Cross-cutting concerns are decorators** — auditing, retry, and rate-limiting wrap a `Transport`; they are never inlined into callers.
8. **Pure where it can be pure** — planning, config layering, reconciliation and redaction take data and return data. Keep I/O at the edges.
9. **Every exception derives from `FleetError`** — with domain context as instance attributes and `raise ... from exc` chaining.
10. **Secrets are `SecretStr`** and never appear in a `repr`, a log, or an audit record.
11. **Never `str()` a value that could be a `Secret`** — use `.reveal()`. `Secret.__str__` returns the mask, which is non-empty and truthy, so every "is it configured" check passes while the credential is gone. A settings loader doing `str(data.get("user"))` authenticated SMB as guest; guest cannot sign, `list()` swallowed the error, and a share holding 8 builds listed as empty. Any config field that may hold a `!ref` is typed `Secret | str` and unwrapped through one reveal helper at the edge.
12. **Mint operation ids through `registry.new_id(prefix)`**, never by formatting a timestamp at the call site. Ids of the form `actor-step-<unix seconds>` collided when a step was rerun inside one second, overwriting the very operation it was rerun from — the failed attempt's logs, the evidence for why it was rerun, gone. `new_id` appends a per-registry sequence under the registry's own lock.
13. **Writers to the artifact share publish by rename.** A dropped session mid-upload left 206MB of a 350MB build under the real name with no sidecar — indistinguishable from a finished artifact, and offered for deploy. Uploads stage to `<name>.uploading`, write the sidecar, then `replace()` into place; `list()` skips staging files. Reads pass `share_access="r"` because `smbclient.open_file()` defaults to exclusive and concurrent sidecar reads collide; writes stay exclusive so a half-written artifact is never readable as complete. **Do not raise `_RETRIES` to compensate** — this is a small router-hosted SMB stack, and 4 retries with backoff exhausted its handles and failed *every* listing. Reproduce contention at the concurrency the log shows, not more.
14. **A transport cannot answer for a pack's capabilities.** Wire verbs (`reach` `facts` `exec` `files` `power`) are the transport's to declare; derived verbs (`state` `apps` `settings` `cleanup`) are built by a pack's managers on top of them. `check_capabilities` is `transport.capabilities() | (provided_by_pack - WIRE_CAPABILITIES)` — a pack adds only what it implements and can never claim `exec` on a dead connection. A plain union was tried first and a test caught it. Same root cause: a transport must not raise the same error for "credential refused" and "host not in `known_hosts`", or discovery reads a stranger as a fleet device and claims the router.
15. **A frequently-polled read is not an operation.** `run_step` exists to give work an operation record, audit trail, policy gating and cancellation; a page-load read gets none of that value and pays the full cost. Implementing `get_base_info`/`check_update` as `run_step` minted a tracked operation on **every** panel load, and when the outbound HTTP call stalled it sat at RUNNING forever, uncancellable, with a fresh one on each refresh. A blocking `urlopen` has no cancellation checkpoint, and a Python thread cannot be killed — `shutdown(cancel_futures=True)` drops only *queued* work. Reserve `run_step` for work a user would want to watch, cancel, or audit; bound cheap reads with a timeout at the adapter. A socket timeout does not cover a DNS stall before the socket opens.
16. **No single stored network field is a device identity.** A MAC identifies an *interface* and an address identifies a *lease*. When a MAC and a serial disagree, **the serial wins** — a box with both ethernet and wifi reports whichever interface answered, so a scan over each describes one device twice. Two devices with differing MACs and *no* serial stay separate: a reused DHCP lease is the ordinary explanation and there is no evidence there. `reconcile` must also collapse the stored fleet before *and* after merging discovery, or a duplicate is unremovable — matching finds only the first record, updates it, and writes both back, so a manual deletion is undone by the next sweep.
